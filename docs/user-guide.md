# Event Planner – User Guide

## 1. Getting Started

Open the Event Planner application in a web browser. Create an account using the signup page, or log in using an existing account.

## 2. Finding Events

Navigate to the Events page to browse available events. Users can search for events by keyword and apply category and date filters to narrow their search. Events can also be viewed using a weekly or monthly calendar.

## 3. Creating an Event

1. Navigate to the "My Events" page.
2. Click the Create Event button.
3. Enter the event name, description, category, date, time, and location.
4. Submit the form to create the event.

The newly created event will appear on the My Events page.

## 4. Managing Events

Navigate to the My Events page and select the event you wish to manage. Event organizers can view event members, manage their roles, generate invitations, and delete their events.

## 5. Inviting Users

From the event management page, generate an invitation for the desired role. The generated invitation link or QR code can be shared with other users. Recipients can follow the invitation and log in or register to join the event.

## 6. Poster Tracking and Analytics

Event organizers can create individual poster tracking QR codes for their events. These QR codes can be downloaded and added to promotional materials.

The analytics interface is designed to display information such as total scans, unique scans, registrations, and conversion rates. Some analytics currently use sample data.
